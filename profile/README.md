# Soffi Originals

Demo apps built in Soffi by an invited group of designers, PMs, and builders. The repos here are live testbeds, so what you see on `main` is whatever the group has shipped to it. Public to read; editing is by invitation.

## The demos

- **[finance-demo](https://github.com/Soffi-Originals/finance-demo)** — Northwind, a personal finance dashboard with balance, spending categories, and recent transactions.
- **[habit-demo](https://github.com/Soffi-Originals/habit-demo)** — Cadence, a journal-style habit tracker with a month-long completion heatmap and warm serif typography.
